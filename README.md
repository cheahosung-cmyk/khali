# khali — 웰스타임 상가 관리 자동화

상가건물 '웰스타임' 관리소장의 업무 반자동화 저장소입니다.

- **`billing/`** — 관리비 반자동화. 수도·전기 고지서 사진을 클로드에 올리면 숫자를 읽어 입력 파일을 만들고, `generate.py`가 세대별 관리비 계산·검산·엑셀·고지서 문구까지 생성합니다. 사용법과 계산 규칙은 [`billing/지침.md`](billing/지침.md) 참고.

## 빠른 사용법

```bash
# 이번 달 입력값(billing/months/2026-07.json)으로 생성
python3 billing/generate.py 2026-07
```

산출물은 `billing/out/2026-07/`에 생깁니다 (엑셀 계산표 + 미납관리 + 세대별 고지서 시트, 문자 발송용 고지서 문구 md). 세대별 미납 잔액은 `billing/ledger.json`에 자동 기록되어 다음 달로 이월됩니다.
