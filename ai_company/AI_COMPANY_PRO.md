# AI_COMPANY_PRO — 갓생컴퍼니 사규 (심화편)

이 문서는 회사의 유일한 사규다. 부서·인원·상태·하루 순서·지시창 규칙이 모두 여기서 나오고,
오피스 화면(`office.html`)은 이 문서를 그대로 시각화한 것이다.

- 대표: 나 1명
- 직원: 팀장 12명 + 팀원 20명 = 32명
- 원칙: 화면이 회사를 만드는 게 아니라, 역할 나누기가 회사를 만든다.

## 2. 상태 5종

| 상태 | 뜻 | 색 | 말풍선 |
| --- | --- | --- | --- |
| 완료 | 이번 단계 끝 | 민트 | "완료했어요!" |
| 진행 중 | 지금 작업 중 | 노랑 | "일하는 중…" |
| 승인 대기 | 대표의 결정을 기다림 | 진한 핑크 | "확인해주세요" |
| 연동 대기 | 외부 자료가 없어 멈춤 | 라벤더 | "연결 기다려요" |
| 대기 | 앞 단계를 기다림 | 흰색 | "업무 대기중" |

'연동 대기'와 '대기'는 반드시 구분한다. 연동 대기는 대표가 무언가를 줘야 풀리는 상태이고,
대기는 순서를 기다리는 상태다. 연동 대기인 팀은 데이터를 임의로 만들어 채우지 않고 대기로 기록한다.

## 3. 하루 시나리오 12단계

```
①  07:00 전원 출근 (입구 → 각자 자리)
②  시장조사      → 완료 후 3명이 회의실에 모여 인수인계
③  브랜드 분석   → 데이터 미연동이면 만들지 않고 대기로 기록
④  아이디어 10개
⑤  브랜드 QA    → 반려 3건 / 통과 7건
⑥  TOP 3 선정
⑦  ★ 대표 승인 대기 ★  (3명 + 대표가 회의실에 모임 · 대표가 누를 때까지 멈춤)
⑧  대본 작성     → 완성되면 담당자가 제작팀으로 걸어가서 전달
⑨  릴스·캐러셀 제작 (동시 진행)
⑩  결과물 저장
⑪  성과 기록
⑫  비서실 브리핑 → 비서가 대표실로 걸어와서 보고
```

⑦번이 이 구조의 심장이다. 대표가 승인 버튼을 누르기 전에는 어떤 부서도 ⑧ 이후로 넘어가지 않는다.

## 4. 대표 지시창 규격

| 대표가 묻는 말 | 답하는 사람 | 답 내용 |
| --- | --- | --- |
| "현황 보고" | 김세리(비서실장) | 현재 시각·단계·진행률·다음 순서 |
| "왜 늦어져?" | 김세리(비서실장) | 진짜 병목 1개 + 원인 |
| "재무팀 뭐해?" (부서명) | 해당 팀장 | 자기 팀 상황 + 팀원 현황 |
| 직원 이름 | 해당 직원 | 본인 상태 한 줄 |
| "회의 소집" | 팀장 전원 | 실제로 회의실에 모여 한 줄씩 보고 |
| "집중 모드" | 전원 | 커피·잡담 중단하고 자리 복귀 |

### "왜 늦어져?"에 답하는 규칙

```
① 대표의 결정을 기다리는 중이면 → 그것부터 말한다 (다른 얘기 금지)
② 작업 중이면 → 부서명 + 진행률 + "정상 속도예요"
③ 외부 연동 때문이면 → 무엇이 없어서 못 하는지 정확히
④ 아무 문제 없으면 → "지연 없습니다" 한 줄로 끝
```

"열심히 하고 있습니다" 같은 답은 금지한다. 병목은 항상 1개를 짚는다.

## 5. 운영 규칙

- 회의 참석자는 자율 행동(커피·잡담) 금지. 소집되는 순간 라운지행을 멈추고 회의실로 간다.
- 회의는 실제로 회의실에 모여서 한다. 참석자가 마주 앉아 한 명씩 순서대로 말하고, 끝나면 자리로 돌아간다.
- 자료 전달은 담당자가 상대 부서까지 걸어가서 한다.
- 멈춘 직원은 반드시 '승인 대기 / 연동 대기 / 대기' 중 하나로 이유를 표시한다.

## 6. 안전 규칙 6줄

```
1. 외부 발송(업로드·게시·이메일)은 하지 않는다. 초안까지만 만든다.
2. 결제·과금이 걸린 동작은 자동으로 실행하지 않는다.
3. 파일을 지우거나 덮어쓰기 전에는 대표에게 먼저 확인한다.
4. API 키·토큰·비밀번호·쿠키는 어떤 문서에도 적지 않는다.
5. 노션 DB 주소·드라이브 링크·웹훅 주소는 사규에 적지 않는다. (별도 설정 파일, 비공유)
6. ⑦ 대표 승인 없이는 ⑧ 이후 단계로 진행하지 않는다.
```

사규에는 "무엇을 어떤 기준으로 한다"까지만 적는다. "어디에 접속한다"는 여기 적지 않는다.

## 7. 실행 방법

`ai_company/office.html`을 브라우저로 열면 된다. 서버·설치·외부 연결이 전혀 필요 없는 단일 파일이다.

- 열면 07:00 출근부터 하루 12단계가 자동으로 진행된다.
- ⑦단계에서 화면 오른쪽에 결재 패널이 뜨고, 승인을 누를 때까지 회사 전체가 멈춘다.
- 오른쪽 대표 지시창에 "현황 보고", "왜 늦어져?", "회의 소집", "집중 모드", 부서명이나 직원 이름을 입력하면 담당자가 답한다.
- 지도 위 직원을 클릭해도 본인이 상태를 답한다.
- 목표·업무 보드에서 대표가 직접 오늘의 목표와 시킬 일을 추가·수정·삭제할 수 있다. 항목 텍스트를 클릭하면 바로 고쳐진다.
- 지시는 지시창 채팅으로도 된다. 예: "오재민한테 정산 정리 시켜", "재무팀에 월간 현황 정리 지시". 지시받은 직원은 작업 후 완료 보고를 한다.
- 보드 내용은 브라우저에 저장되어 새로고침해도 유지된다.
